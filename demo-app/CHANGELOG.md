## [0.1.0] - 2026-11-28

### Added
- Official BlaiseVue Enterprise Universal Showcase Application (`demo-app`).
- Reactive SPA showcase views covering forms validation (`b-validate`), `BVDataGrid`, BlaiseUI Kit, Chart.js integrations, i18n (`en`, `pt`, `el`), Capacitor mobile layout, offline dataset sync, Wasm/Pro features, and Reports.
- Built-in Vitest + `BVTestUtils` unit test coverage across components, services, and all showcase views.
