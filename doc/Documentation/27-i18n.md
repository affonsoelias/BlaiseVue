# 27. Integrated Internationalization (Blaise-i18n)

BlaiseVue 2.5 provides native multi-language support through **Blaise-i18n**. It enables fine-grained reactive translations, nested key lookup, token interpolation, and dynamic locale switching without page reload.

---

## 🎯 Key Features

- **Global Template Helper `$t(key, params)`**: Immediate translation resolution in templates (`{{ $t('common.save') }}`).
- **Dynamic Locale Switching**: Changing `$i18n.locale := 'pt'` triggers dependency tracking and automatically updates all translated strings in the DOM.
- **Nested Dictionaries**: Organize message catalogs using nested objects (`auth.login.title`).
- **Token Interpolation**: Pass dynamic arguments to translations (`{{ $t('welcome', { name: userName }) }}`).
- **Fallback Locales**: Missing translations gracefully fall back to a specified secondary language (e.g. `'en'`).

---

## 🚀 Setting Up Internationalization

### In Root Application (`app.bv` or `main.pas`)

```pascal
uses BlaiseVue, BVI18n, JS;

procedure InitI18n;
var
  EnMsgs, PtMsgs: TJSObject;
begin
  TBVI18n.Init('en', 'en'); // defaultLocale, fallbackLocale

  // English messages
  asm
    EnMsgs = {
      common: { save: 'Save', cancel: 'Cancel' },
      welcome: 'Welcome, {name}! You have {count} notifications.'
    };
    PtMsgs = {
      common: { save: 'Salvar', cancel: 'Cancelar' },
      welcome: 'Bem-vindo, {name}! Você tem {count} notificações.'
    };
  end;

  TBVI18n.AddMessages('en', EnMsgs);
  TBVI18n.AddMessages('pt', PtMsgs);
end;
```

## 💻 Using Translations in Templates

```html
<template>
  <div class="user-greeting">
    <!-- Basic translation -->
    <h1>{{ $t('common.save') }}</h1>

    <!-- Translation with parameter interpolation -->
    <p>{{ $t('welcome', { name: currentUser, count: pendingCount }) }}</p>

    <!-- Dynamic language selector -->
    <div class="lang-picker">
      <button @click="$setLocale('en')">English 🇺🇸</button>
      <button @click="$setLocale('pt')">Português 🇧🇷</button>
    </div>
  </div>
</template>

<script>
  data:
    currentUser: string = 'Affonso';
    pendingCount: integer = 4;

  methods:
    procedure switchLanguage(newLocale: string);
    begin
      // Accessible inside Pascal methods:
      this['$setLocale'](newLocale);
      console.log('Current translated action:', this['$t']('common.save'));
    end;
</script>
```

## 🛠️ Programmatic API (`TBVI18n`)

| Method | Description |
|---|---|
| `TBVI18n.Init(DefaultLocale, FallbackLocale)` | Initializes i18n with active and fallback language codes. |
| `TBVI18n.SetLocale(ALocale)` | Updates active locale and triggers re-render of all `$t` references. |
| `TBVI18n.GetLocale` | Returns current active locale string (e.g. `'en'`). |
| `TBVI18n.AddMessages(ALocale, MessagesObject)` | Merges translation dictionary for the given locale. |
| `TBVI18n.T(Key, Params = nil)` | Resolves translation string with optional parameter object. |
| `TBVI18n.Has(Key, ALocale = '')` | Checks if a translation key exists in dictionary. |
