# 49 - BlaiseReports: Native Vector PDF, Excel & Print Engine

**BlaiseReports** (`packages/blaise-reports`) is the official enterprise reporting and multi-format document export engine introduced in **BlaiseVue 5.0 (Pillar 1)**. Written in 100% pure Object Pascal, it enables seamless generation of native **Vector PDF 1.4** documents, **Excel (`.xlsx` / SpreadsheetML)** spreadsheets, **RFC 4180 CSV** streams with UTF-8 BOM, and **Print-Optimized HTML** layouts (including A4, Letter, and 80mm/58mm Thermal POS receipts) directly from `TBVDataSet` instances or JSON record arrays.

---

## 📦 Installation

Install the official `blaise-reports` package into your project using the BlaiseVue CLI:

```bash
bv lib install reports
```

Or copy `packages/blaise-reports` into `lib/blaise-reports`. The core unit `BlaiseReports.pas` is also included directly in `core/BlaiseReports.pas` and exposed through `BVPascalDX.pas`.

---

## 🏗️ Architectural Overview

`BlaiseReports` is designed around four pillars:

1. **Declarative Fluent Engine (`TBVReport`)**: Bind to any `TBVDataSet` or `TJSArray`, define columns (`field:Caption:format:align:width`), configure headers/footers/branding, and attach summary aggregates (`aggSum`, `aggAverage`, `aggCount`, `aggMin`, `aggMax`).
2. **Multi-Format Document Exporters**:
   - **`ExportPDF` / `GeneratePDF`**: Native Vector PDF 1.4 engine using standard Type1 vector fonts (`/Helvetica`, `/Helvetica-Bold`), vector header banners, alternating zebra-striped rows, automatic multi-page pagination, running `"Page X of Y"` footers, summary bands, and a valid `xref` cross-reference table.
   - **`ExportExcel` / `GenerateExcel`**: Native Excel SpreadsheetML (`.xlsx`) generator preserving strongly typed cells (`Number`, `Currency`, `Integer`, `Boolean`, `String`), header themes, and summary rows.
   - **`ExportCSV` / `GenerateCSV`**: Streaming RFC 4180 CSV generator with configurable delimiter (`,` or `;`), automatic quote escaping, and optional UTF-8 BOM (`\uFEFF`) for direct Excel compatibility.
3. **Print & Thermal POS Layout Engine (`PrintPreview` / `GeneratePrintHTML`)**: Generates print-ready HTML with `@media print` and `@page` rules tailored for `A4 Portrait`, `A4 Landscape`, `Letter`, `Thermal 80mm`, and `Thermal 58mm` receipt printers.
4. **Interactive `<bv-report-viewer>` Component**: A drop-in Single File Component (`BVReportViewer.bv`) providing a live document preview sheet, page layout switcher, summary KPI cards, and 1-click export buttons.

## 🚀 Quick Start (Fluent Object Pascal API)

```pascal
uses
  BVDataSet, BlaiseReports;

procedure GenerateSalesReport(SalesDS: TBVDataSet);
var
  Report: TBVReport;
begin
  Report := TBVReport.Create(SalesDS);
  Report.Title('Q4 Executive Sales Summary')
        .Subtitle('Consolidated Regional Performance')
        .Company('BlaiseVue Enterprise Corp.')
        .LogoText('BV-ERP')
        .Header('Generated by Finance Module | Fiscal Year 2026')
        .Footer('Confidential - Internal Audit Only')
        .ThemeColor('#1e293b')
        .CurrencySymbol('$')
        .RowsPerPage(25)
        .Columns([
          'id:Invoice #:integer:center:70',
          'customer:Customer Name:string:left:180',
          'category:Segment:string:left:130',
          'total:Total Amount:currency:right:110'
        ])
        .AddSummary('total', aggSum, 'Grand Total Revenue', 'currency')
        .AddSummary('total', aggAverage, 'Average Order Value', 'currency')
        .AddSummary('id', aggCount, 'Total Invoices', 'integer');

  // Trigger browser download of a native Vector PDF
  Report.ExportPDF('q4_sales_summary.pdf');

  // Or export to Excel (.xlsx) / CSV (.csv)
  Report.ExportExcel('q4_sales_summary.xlsx');
  Report.ExportCSV('q4_sales_summary.csv');
end;
```

## ✨ Zero-ASM Pascal DX Helpers (`BVPascalDX.pas`)

For 100% Zero-ASM views and components, `BVPascalDX` provides high-level procedural wrappers:

```pascal
uses
  BVDataSet, BVPascalDX;

procedure ExportQuickReport(DS: TBVDataSet);
var
  Rep: TBVReport;
begin
  Rep := NewReport(DS);
  ReportSetTitle(Rep, 'Inventory Valuation Report', 'Warehouse A');
  ReportSetHeader(Rep, 'Stock Audit 2026', 'Page Footer');
  ReportSetCompany(Rep, 'Acme Logistics', 'ACME');
  ReportSetPageLayout(Rep, 'a4-landscape');
  ReportSetColumns(Rep, ['sku:SKU', 'title:Product', 'price:Unit Price:currency']);
  ReportAddSummary(Rep, 'price', aggSum, 'Total Valuation', 'currency');

  ReportExportPDF(Rep, 'inventory.pdf');
end;
```

| Helper Function | Description |
| :--- | :--- |
| `NewReport(ADataSource)` | Instantiates a new `TBVReport` bound to a `TBVDataSet` or JS array. |
| `ReportSetTitle(AReport, ATitle, ASubtitle)` | Sets the primary title and optional subtitle. |
| `ReportSetHeader(AReport, AHeader, AFooter)` | Configures running header metadata and footer text. |
| `ReportSetCompany(AReport, ACompany, ALogoText)` | Configures company name and badge logo text. |
| `ReportSetPageLayout(AReport, ALayout)` | Sets layout: `'a4'`, `'a4-landscape'`, `'letter'`, `'thermal-80mm'`, `'thermal-58mm'`. |
| `ReportSetColumns(AReport, AColumns)` | Defines report columns using shorthand strings (`'field:Caption:format'`). |
| `ReportAddColumn(...)` | Appends a single strongly-typed column definition. |
| `ReportAddSummary(...)` | Registers an aggregate calculation (`aggSum`, `aggAverage`, `aggCount`, `aggMin`, `aggMax`). |
| `ReportComputeSummary(...)` | Evaluates and returns the numeric aggregate for a field. |
| `ReportExportPDF(AReport, AFileName)` | Generates and downloads a Vector PDF 1.4 file. |
| `ReportExportExcel(AReport, AFileName)` | Generates and downloads an Excel `.xlsx` spreadsheet. |
| `ReportExportCSV(AReport, AFileName)` | Generates and downloads an RFC 4180 `.csv` file with UTF-8 BOM. |
| `ReportPrintPreview(AReport, ATargetId)` | Generates print-optimized HTML and optionally injects it into a DOM container. |

### Supported Page & Thermal POS Layouts

| Enum (`TBVPageLayout`) | Shorthand String | Target Media / Dimensions |
| :--- | :--- | :--- |
| `plA4Portrait` | `'a4'` | Standard ISO A4 Portrait (`210mm × 297mm` / `595pt × 842pt`) |
| `plA4Landscape` | `'a4-landscape'` | Standard ISO A4 Landscape (`297mm × 210mm` / `842pt × 595pt`) |
| `plLetterPortrait` | `'letter'` | US Letter Portrait (`8.5in × 11in` / `612pt × 792pt`) |
| `plLetterLandscape` | `'letter-landscape'` | US Letter Landscape (`11in × 8.5in` / `792pt × 612pt`) |
| `plThermal80mm` | `'thermal-80mm'` | POS Thermal Receipt Printer (`80mm` roll width, monospace) |
| `plThermal58mm` | `'thermal-58mm'` | Compact POS Thermal Printer (`58mm` roll width, monospace) |
